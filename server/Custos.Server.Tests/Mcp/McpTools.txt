# Each MCP tool of the server, with its guard, its arguments, and its description.
#
# A snapshot, not configuration. Nothing reads it at runtime. McpToolTests compares it with the
# assembly. The server refuses each call of a tool without a guard, and a guard that someone
# changes gives no build error, so this file is where a reviewer sees the change.
#
# One line for each tool:   name | Type.Method | scope, access | arguments | description
#
#   access       the access of the caller in the guild of the argument guild_id. None: the guard
#                examines the token only.
#   arguments    name:type for each argument of the input schema, in order. ? marks an argument
#                with a default.
#   description  the [Description] of the tool, which the model reads.
#
# A change of a tool is a change of this file. Blank lines and # comments do not count.

list_guilds | GuildTools.ListGuilds | Read, None | none | The Discord guilds of the Custos bot where you are a member: the guild ID, the name, your access, the current war, and the guilds that share their records with it.
find_items | SearchTools.FindItems | Read, Read | guild_id:string, items:string[]?, stockpiles:string[]?, structures:string[]?, structure_categories:string[]?, war:int?, limit:int?, cursor:string? | The stockpiles that hold an item, with the quantities. One row for each item in each stockpile, and one total for each item. Filters: items (code name or name), stockpiles (ID, part of a name, or public), structures (ID or part of a label), and structure_categories. war is a war number, and the default is the current war.
find_structures | SearchTools.FindStructures | Read, Read | guild_id:string, structures:string[]?, structure_categories:string[]?, items:string[]?, stockpiles:string[]?, war:int?, limit:int?, cursor:string? | The structures, with their labels, places, stockpiles, and items. One row for each structure. Filters: structures (ID or part of a label), structure_categories, items (code name or name), and stockpiles (ID, part of a name, or public). war is a war number, and the default is the current war.
set_structure_label | LabelTools.SetStructureLabel | Write, Label | guild_id:string, structure_id:string, label:string? | Change the label of a structure in the records of the guild. Without a label, the generated label shows again. A label has 1 to 64 characters: letters, digits, spaces, and - ' . , ( ) / & +. It is unique in the guild and the war.
