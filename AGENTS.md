# Agents

This file is the minimum. The nearest `AGENTS.md` below the root is authoritative for its folder.

## Read before work in a project

1. The `README.md` of the project.
2. The `AGENTS.md` of the project, if present.
3. [GOVERNANCE.md](GOVERNANCE.md), if the work changes structure, process, or rules for agents.

The rules that apply now are in these files. Read an ADR only to learn why a rule exists, or before you change a decision. Start from the [ADR index](docs/adr/README.md).

## Rules

- Do not add content to a root file that belongs to one project.
- Record a decision that meets the test in [GOVERNANCE.md](GOVERNANCE.md) as an ADR. Merge it before or together with the change that depends on it.
- Treat an ADR as in force only when it is on `main` or on another shared branch.
- Change the status of a merged ADR only when the Maintainer instructs it.
- Hold discussions in GitHub issues and pull requests. Write a note in the repository only when the Maintainer asks for one.
