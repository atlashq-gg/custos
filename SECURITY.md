# Security

Custos holds an authentication context from a remote service on the machine of a player. A server holds the reports of many players. Report a vulnerability in either one privately.

## Report a vulnerability

1. Open the **Security** tab of this repository on GitHub.
2. Select **Report a vulnerability**.
3. Give the affected project (`custos`, `spec`, or `server`), the version or commit, and the steps to reproduce the problem.

Do not open a public issue for a vulnerability.

## Supported versions

No version is released yet. After the first release, only the latest release of each project gets security fixes.
